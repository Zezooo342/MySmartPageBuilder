# Code of Conduct

This project adopts a shortened form of the Contributor Covenant v2.1.

## Our Pledge
We pledge to make participation harassment-free for everyone.

## Standards
Positive examples: empathy, constructive feedback, inclusivity.
Unacceptable: harassment, personal attacks, trolling, hate speech.

## Enforcement
Report issues to the maintainer. Repeated violations may result in temporary or permanent bans from participation.
