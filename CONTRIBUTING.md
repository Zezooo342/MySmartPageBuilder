# Contributing Guide

## Workflow
1. Fork / create a feature branch.
2. Implement changes (keep commits atomic).
3. Add or update tests (later when test suite exists).
4. Open a Pull Request with clear description.

## Commit Style
Conventional style encouraged (e.g., feat:, fix:, docs:, refactor:).

## Directory Rules
- core/: foundational abstractions only.
- components/: each component in its own folder.
- renderer/: pipeline + helpers.

## Roadmap Updates
If you add a feature, update the README roadmap checklist where appropriate.
